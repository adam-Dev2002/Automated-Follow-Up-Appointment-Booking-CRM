# Application screenshots

Generated from the actual application with fictional clients and a disposable database. No production database, live n8n workflow, or Gmail account is contacted.

Desktop previews all use a 1440 x 1050 viewport, including the client modal. Complete page captures are in `full/`; mobile captures retain their full page so the details remain available. The sidebar rail and card alignment are application styles, not screenshot edits.

Regenerate with `npm run screenshots`. Dates follow the current Asia/Manila calendar.
